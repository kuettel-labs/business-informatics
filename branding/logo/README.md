# kuettel-labs logo

The official kuettel-labs logo (concept C: a "k" built from blocks, with a teal accent).

| File | Use |
|---|---|
| `logo_color.svg` / `logo_color.png` | Primary logo in color, for light backgrounds |
| `logo_mono_black.svg` / `logo_mono_black.png` | One-color black version |
| `logo_mono_white.png` | One-color white version, for dark backgrounds |
| `avatar.svg` / `avatar.png` | Square mark only, for profile pictures and app icons |
| `receipt_bw.png` | Small black-and-white version for receipt printers (384 px wide) |

Prefer the SVG files; the PNGs are exports for places that need bitmaps.

## Font

The wordmark uses **Space Grotesk**, licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/). In the SVG files the lettering is converted to outlines, so no font file is needed or distributed here.
