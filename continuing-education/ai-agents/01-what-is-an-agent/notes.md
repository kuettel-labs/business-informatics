# What an agent is

**Week 1.** Path: [Introduction to building AI agents](https://learn.microsoft.com/en-us/training/paths/build-foundation-extend-microsoft-365-copilot/), module *Introduction to developing AI agents*.

## Key concepts

- [ ] Model: the language model that proposes the next step
- [ ] Instructions: the standing rules for role, tone, and refusal
- [ ] Tools: actions the agent may call (search, ticket, database, HTTP)
- [ ] Knowledge: documents or an index the answer must come from
- [ ] Orchestration: the loop that calls a tool, reads the result, and decides whether to stop
- [ ] A chatbot turn answers once. A workflow runs a sequence you drew. An agent loop chooses the next action from the result of the last one
- [ ] A fixed approval chain stays a workflow. An agent earns its cost when the next step depends on what the tool returned
