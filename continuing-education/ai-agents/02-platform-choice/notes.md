## Key concepts

- [ ] Copilot Studio: low-code agents, topics, generative orchestration, publish to Microsoft 365 channels
- [ ] Microsoft Foundry Agent Service: Azure-hosted agents, tools, knowledge, and the Agent Framework SDK
- [ ] Microsoft 365 Agents Toolkit: agents that extend Microsoft 365 Copilot
- [ ] Outcome, success metric, data sources, channel, identity, and a responsible-AI note belong in the plan before the first prompt
- [ ] Connected agents and child agents are week 8 material. Week 2 picks one surface for the capstone
