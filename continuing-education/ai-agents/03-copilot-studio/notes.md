# Copilot Studio

**Week 3.** Module: [Get started with Microsoft Copilot Studio](https://learn.microsoft.com/en-us/training/modules/power-virtual-agents-bots/).

Use a non-production environment. The module compares authoring harnesses; follow the harness the module marks as the default for topics and the test panel, and write down the name you actually used.

## Key concepts

- [ ] Environment and who can edit the agent
- [ ] Create an agent and set instructions
- [ ] Topics for the paths you want to control
- [ ] Generative orchestration for the paths you are willing to let the model choose
- [ ] Test panel: three questions you wrote in week 2, plus the refusal
- [ ] Publish target, and what "published" exposes
- [ ] Analytics you would check after a real user tried it

## Exercise

Script four prompts before you open the test panel: three in scope, one that should be refused. Record the answers. If the refusal answers anyway, change the instructions and test again.
