# Foundry and the Agent Framework

**Week 4.** Path: [Develop AI agents on Azure](https://learn.microsoft.com/en-us/training/paths/develop-ai-agents-azure/). Do these two modules this week:

1. Develop AI agents with Microsoft Foundry and Visual Studio Code
2. Develop an AI agent with Microsoft Agent Framework

The path lists the framework module after tools and knowledge. Do it now so you have a loop to hang tools on in week 6. Leave the tool, MCP, and Foundry IQ modules for weeks 5 and 6.

Book: Narayn, chapter 2 (re-read while you build). Confirm the title against the Calibre copy (folder 1843).

## Key concepts

- [ ] A Foundry agent: model, instructions, tools, and a thread of messages
- [ ] Portal path and Visual Studio Code path both create an agent you can test
- [ ] The Agent Framework SDK is how you build that agent in code
- [ ] A tool call is visible in the trace. If you cannot see the call, you cannot debug the answer
- [ ] Delete the Azure resources when the lab log says the result is recorded

## Exercise

Run one agent that calls one trivial tool (for example, today's date or a status you hard-code). Paste the trace, not the whole transcript, into **My notes**: the user message, the tool name, the tool result, the final answer.
