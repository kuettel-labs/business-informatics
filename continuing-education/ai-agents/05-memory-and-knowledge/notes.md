## Key concepts

- [ ] Instructions tell the agent how to behave. Knowledge is the source the answer must come from. Mixing them makes citations meaningless
- [ ] Short-term memory is the current thread. Persistent memory is stored between threads. Semantic recall is search over embeddings
- [ ] RAG: retrieve passages, then generate from those passages
- [ ] Foundry IQ is the shared knowledge layer described in the module. Several agents can use one knowledge setup
- [ ] Chunking, hybrid search, and ranking change which passage comes back. You judge quality by the citation, not by how fluent the answer sounds
- [ ] An answer with no supporting passage is a miss, even when the prose looks right
