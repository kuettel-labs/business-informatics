# Trust and governance

**Week 7.** Book: Narayn, chapters 6 and 8 (trust, then going live). Learning path: [Responsible AI business principles](https://learn.microsoft.com/en-us/training/paths/responsible-ai-business-principles/). Law text, read for scope only: [DSG](https://www.fedlex.admin.ch/eli/cc/2022/491/de).

## Key concepts

- [ ] Identity: which user the agent acts as, and which user it may impersonate
- [ ] Data minimisation: the knowledge source and the tool see only what the answer needs
- [ ] Prompt injection: untrusted text in a document or a tool result can try to override the instructions
- [ ] Refusal: the cases from week 2 are tests, not a slogan in the system prompt
- [ ] Observability: you can reconstruct tool name, arguments, result, and final answer after the fact
- [ ] A published agent is a service. It needs an owner, a cost ceiling, and a way to turn it off
- [ ] The DSG page is the statute. A lawyer or your organisation's privacy role decides whether a use falls under it
