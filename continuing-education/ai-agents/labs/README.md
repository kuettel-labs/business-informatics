# Hands-on labs

Use a free Azure subscription, a sandbox, or a non-production Copilot Studio environment. Delete the resources when the log entry is complete.

Suggested labs, one per build week. Log them with the template. Put newer entries at the top.

| Week | Lab | Pass check |
| --- | --- | --- |
| 3 | Copilot Studio agent with three in-scope prompts and one refusal | Refusal does not answer the forbidden question |
| 4 | Foundry or Agent Framework agent with one trivial tool | Trace shows tool name and tool result |
| 5 | Five of your own notes as the knowledge source | Two cited hits and one honest miss |
| 6 | One read-only custom tool, one valid call and one invalid call | Invalid call fails inside the tool |
| 8 | Capstone demo | Question, citation, refusal, resources deleted |
