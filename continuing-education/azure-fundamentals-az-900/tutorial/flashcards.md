# AZ-900 flashcards (15 minutes, exam morning)

| Q | A |
| --- | --- |
| CapEx vs OpEx? | Upfront assets vs pay-as-you-go spending; cloud = OpEx |
| Always the customer's, in any model? | Data, devices, accounts and identities |
| Who patches the OS in PaaS? | Microsoft |
| IaaS example? | Azure Virtual Machines |
| PaaS example? | App Service, Azure SQL Database |
| SaaS example? | Microsoft 365 |
| Scale up vs scale out? | Bigger resource vs more instances |
| Elasticity? | Automatic scaling up and down with demand |
| Serverless example? | Azure Functions, Logic Apps |
| Hierarchy top to bottom? | Management group > subscription > resource group > resource |
| Resource in how many resource groups? | Exactly one |
| Availability zone? | Separate datacenter(s) within one region |
| Region pair purpose? | Regional DR, staged updates, GRS target |
| Sovereign regions? | Azure Government, Azure China (21Vianet) |
| Availability set protects against? | Rack and update failures in one datacenter |
| VM Scale Sets? | Identical autoscaling VMs |
| Single container, no orchestration? | Azure Container Instances |
| Managed Kubernetes? | AKS |
| Hosted Windows desktops? | Azure Virtual Desktop |
| Private link to on-premises, no internet? | ExpressRoute |
| Encrypted tunnel over internet? | VPN Gateway |
| Connect two VNets without gateway? | VNet peering |
| NSG vs Azure Firewall? | Free basic IP/port rules vs paid stateful central firewall |
| Private endpoint? | Private IP in your VNet for a PaaS service |
| LRS / ZRS / GRS / GZRS? | 1 datacenter / 3 zones / + paired region / zones + paired region |
| RA- prefix? | Secondary region readable |
| Cool / cold / archive minimum? | 30 / 90 / 180 days; archive offline |
| AzCopy vs Storage Explorer? | CLI vs GUI |
| Sync file server with Azure Files? | Azure File Sync |
| Offline bulk transfer? | Azure Data Box |
| Assess and migrate servers? | Azure Migrate |
| Azure AD new name? | Microsoft Entra ID |
| Managed LDAP/domain join? | Microsoft Entra Domain Services |
| Partners as guests? | B2B collaboration |
| If-then sign-in rules? | Conditional Access |
| Zero Trust principles? | Verify explicitly, least privilege, assume breach |
| Security posture and secure score? | Microsoft Defender for Cloud |
| Who can do what? | RBAC |
| What resources may look like? | Azure Policy |
| Stop deletion even by Owner? | CanNotDelete lock |
| Tags inherited? | No (use Policy) |
| Estimate new costs? | Pricing calculator |
| Track actual spend and budgets? | Cost Management |
| Data governance and classification? | Microsoft Purview |
| Manage non-Azure servers in Azure? | Azure Arc |
| Declarative IaC in Azure? | ARM templates, Bicep |
| Recommendations? | Azure Advisor |

| Query logs (KQL)? | Log Analytics |
