# 9. RACI for the ERP Project Specialist

R = responsible, A = accountable, C = consulted, I = informed. Role set: PM (project manager), SA (solution architect / lead consultant), SPEC (ERP Project Specialist), DO (data owner), KU (key user), IT (infrastructure).

| Activity | PM | SA | SPEC | DO | KU | IT |
|---|---|---|---|---|---|---|
| Migration strategy and scope | A | R | C | C | I | I |
| Data object inventory and load sequence | I | A | R | C | I | I |
| Data profiling | I | C | R/A | I | C | C |
| Cleansing rules | I | C | R | A | C | I |
| Cleansing execution in source | I | I | C | A | R | I |
| DMT mapping workbook | I | A | R | C | C | I |
| Value mappings and defaults | I | C | R | A | C | I |
| DMF projects, templates, jobs | I | A | R | I | I | C |
| Custom data entities | I | A/R | C | I | I | I |
| Iteration execution and logs | I | A | R | I | I | C |
| Reconciliation | I | C | R | A | C | I |
| Defect logging and tracking | I | C | R/A | I | C | I |
| Test documentation | C | C | R | I | C | I |
| Cutover runbook | A | C | R | C | C | C |
| Go / no go | A | C | C | C | I | C |
| Project backlog and change requests | A | C | R | C | I | I |
| Minutes, action items, status reports | A | I | R | I | I | I |
| Technical documentation for PMO | A | C | R | I | I | C |
| First level analysis of system, interface and performance issues | I | A | R | I | C | C |
| User training support and handover to operations | A | C | R | I | C | C |

This RACI is a suggested model shaped by a typical role description, not a sourced standard (**UNVERIFIED** as a norm).

## Handlungskompetenzbereiche

Relevant competences from the official qualification profile of the Berufsprüfung Wirtschaftsinformatiker/in ([Wegleitung vom 2. Dezember 2024](https://www.ict-berufsbildung.ch/resources/20241202_WL_QP_FAWIR_de.pdf)):

* **b6: Mitarbeitende und Teams führen** (Bereich b: ICT Projekten leiten). The RACI defines roles and responsibilities for leading the team.
* **b1: Bedürfnisse von Anspruchsgruppen erheben und diese mit geeigneten Methoden abbilden** (Bereich b: ICT Projekten leiten). Assigning data owners and business roles involves the stakeholders.
