# Phase 7: Hypercare

Goal: stabilise operations after go-live and hand over to support ([Newell, ch. 21]; [Newell, ch. 22]).

| Area | Activities |
|---|---|
| Issue triage | Daily stand up, defect log, priority by business impact |
| Data corrections | Fix residual data issues with data entities and the Data management workspace; log every manual correction ([Learn: import/export jobs](https://learn.microsoft.com/en-us/dynamics365/fin-ops-core/dev-itpro/data-entities/data-import-export-job)) |
| First period end | Support the first month end close and reconcile against AX 2009 closing balances |
| Archive access | Confirm users can find history in the archive or BYOD ([Solution Architect, ch. 5]) |
| Handover | Documentation, known issues, open change requests to support and PMO |

Duration of 4 to 8 weeks is an assumption (**UNVERIFIED**).

## Exit criteria

- [ ] First period close done and reconciled
- [ ] No open severity 1 issues
- [ ] Support team accepted the handover documentation
- [ ] AX 2009 decommission plan agreed (read only retention)
