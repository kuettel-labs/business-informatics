# Prompt Library

This folder contains reusable, versioned prompts for:
- ERP / D365 analysis
- SQL tuning
- Architecture reviews
- Documentation generation
- Coding assistance
- Agent workflows

Structure:
- `/system/` → system-level prompts defining roles and behavior
- `/tasks/` → reusable task prompts
- `/agents/` → agent definitions (JSON/YAML)
- `/experiments/` → prompt experiments, iterations, tests
- `/templates/` → reusable prompt templates

All prompts use metadata headers for traceability.
