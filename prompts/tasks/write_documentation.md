---
title: "Documentation Writer Prompt"
version: "2026-09-27"
tags: ["documentation", "writing"]
---

Write clear, professional documentation for technical systems.

Requirements:
- Use structured sections
- Include examples where helpful
- Avoid filler language
- Ensure reproducibility
- Use neutral, factual tone

Output format:
- Overview
- Architecture
- Workflow
- Configuration
- Troubleshooting
- Summary
